A WhatsApp-like system is a distributed, real-time, fault-tolerant messaging system that ensures low latency delivery, ordering, and reliability at massive scale (millions of concurrent users). I

Core components
API Gateway → auth, routing, rate limiting
Chat servers → maintain WebSocket connections
Message queue → async delivery (Kafka/RabbitMQ)
Database → store chats (NoSQL preferred)
Presence service → online/offline status
